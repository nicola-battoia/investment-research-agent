# Data

Local data artifacts for development live here.

- `downloads/` holds raw source files fetched from SEC EDGAR, grouped by year.
- `markdown/` holds clean Markdown generated by the SEC-specific parser.
- `parsed_documents/` holds the parser's sections, blocks, and table geometry.
- `ingestion_runs/sec_sections_v2/` holds resumable per-document chunk and embedding
  checkpoints generated by the active ingestion scripts.
- `archive/docling_documents/` contains unused legacy Docling outputs kept only for
  local comparison.
- Corpus payloads and generated documents are gitignored because they can get large.
- Fetch a sample corpus with `uv run data/download.py`.
- Parse downloads from `backend/` with
  `uv run python -m ingestion.parse_documents`.
- See `backend/ingestion/README.md` for the complete checkpointed pipeline.
